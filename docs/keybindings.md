# 键位说明

TUI 分为四种交互模式：导航、搜索、表单、确认。列表/搜索模式在底部状态栏显示当前模式，表单和浮层使用顶部标题栏。

键位记法：`↑/↓` 表示方向键，`ctrl+n` 表示组合键，`esc` 表示 Escape。鼠标交互在 v1 中不启用。

## 导航模式（默认）

| 键 | 行为 |
|---|---|
| `↑` / `k` | 上移 |
| `↓` / `j` | 下移 |
| `ctrl+p` / `ctrl+n` | 上移 / 下移（与输入法冲突时使用） |
| `g` | 跳到首行 |
| `G` | 跳到末行 |
| `enter` | 连接选中服务器 |
| `/` | 进入搜索模式 |
| `a` | 新增服务器 |
| `e` | 编辑选中服务器 |
| `d` | 删除选中服务器（需确认） |
| `f` | 切换收藏 |
| `c` | 复制等效的 ssh 命令到剪贴板 |
| `?` | 打开帮助 |
| `q` | 退出 |
| `ctrl+c` | 退出 |

列表为空时：`a` 新增，`i` 从 `~/.ssh/config` 导入，`q` 退出。

`c` 复制的命令与 AddressPad 实际执行的一致，例如：

```bash
ssh -p 2222 -i ~/.ssh/id_ed25519 -J bastion -- deploy@10.0.1.5
```

剪贴板实现：macOS 用 `pbcopy`，Windows 用 PowerShell `Set-Clipboard`（显式 UTF-8 输入，避免中文乱码），Linux 依次尝试 `wl-copy`、`xclip`、`xsel`。全部不可用时打开命令展示页供手动复制，`esc` / `q` 返回。Windows 复制内容使用 PowerShell 语法，其他系统使用 POSIX shell 语法，每个参数都进行引号转义。

## 搜索模式

进入时自动聚焦输入框，输入内容实时过滤。

| 键 | 行为 |
|---|---|
| 任意字符 | 追加过滤条件 |
| `backspace` | 删除最后一个字符 |
| `ctrl+w` | 删除最后一个词 |
| `ctrl+u` | 清空过滤条件 |
| `enter` | 连接当前高亮项 |
| `esc` | 返回导航模式，保留过滤结果 |
| `ctrl+c` | 退出程序 |

匹配规则：

- 对 `name`、`user`、`host`、`group`、`tags` 做大小写不敏感的子序列匹配
- 空格分隔多个关键词，需全部命中（AND）
- 结果为空时列表区显示 “no match”，`esc` 清除

## 表单模式

新增与编辑共用同一表单，字段顺序：

1. 名称 `name`（必填）
2. 主机 `host`（必填）
3. 用户 `user`
4. 端口 `port`
5. 私钥 `identity_file`
6. 跳板 `proxy_jump`
7. 分组 `group`
8. 标签 `tags`（逗号分隔）
9. 备注 `note`
10. 收藏 `favorite`（开关）
11. 密码 `password`（隐藏输入，写入系统钥匙串）
12. 保存密码 `password_saved`（开关，默认勾选）
13. 额外参数 `extra_args`（空格分隔，支持单/双引号与反斜线转义，不执行 shell 展开；Windows 路径建议放在单引号内）

| 键 | 行为 |
|---|---|
| `tab` / `↓` | 下一个字段 |
| `shift+tab` / `↑` | 上一个字段 |
| `enter` | 非最后字段时跳到下一个；最后字段时保存 |
| `ctrl+s` | 保存 |
| `esc` | 取消 |
| `ctrl+c` | 取消并退出程序 |

说明：

- 多行备注用 `alt+enter` 换行
- 密码字段隐藏输入；编辑时留空会保留原密码。`Save password` 默认勾选，取消勾选会删除已保存密码；填写了密码但未勾选会阻止保存
- 密码保存成功后立即从表单清空，配置文件只写入 `password_saved` 标记
- 校验失败时在对应字段下方显示红色提示，焦点自动跳到第一个出错字段
- 有未保存修改时按 `esc` 弹出确认：`y` 放弃修改，`n` 继续编辑
- 保存成功返回列表并高亮该条目；保存失败（磁盘只读等）保留表单内容

## 删除确认

| 键 | 行为 |
|---|---|
| `y` / `enter` | 确认删除并保存 |
| `n` / `esc` | 取消 |

确认框显示待删除的 `name` 与 `user@host`，避免误删同名机器。

## 帮助浮层

| 键 | 行为 |
|---|---|
| `?` | 关闭 |
| `esc` | 关闭 |
| `q` | 关闭（不退出程序） |

帮助浮层打开时其他按键不生效。

## 状态栏提示

状态栏左侧的 `|` 标记当前结果：成功为绿色，失败或警告为红色。操作结果在底部显示 3 秒后自动消失；失败与警告保留到下一次操作。

| 事件 | 文案 |
|---|---|
| 保存成功 | `saved prod-web-1` |
| 删除成功 | `deleted staging` |
| 收藏切换 | `pinned prod-db` / `unpinned prod-db` |
| 复制成功 | `copied: ssh -p 22 …` |
| SSH 退出 | `SSH session ended (exit code 0); back in AddressPad` / `(exit code 255)` |
| 保存失败 | `save failed: permission denied`（停留到下次操作） |
